# DEF-012 : Le portfolio ne présentait pas le projet de tests

| Champ | Valeur |
|---|---|
| Gravité | Majeure |
| Priorité | Haute |
| Statut | Corrigé (portfolio, commit `3d9da97`) |
| Environnement | Page d'accueil du portfolio, tous navigateurs |
| Test de non-régression | TC-API01, scénario BDD « Trouver le projet QA et son code » |

## Étapes pour reproduire

1. Ouvrir la page d'accueil du portfolio.
2. Chercher, dans la section Projets, un lien vers `github.com/mireille-kafando/qa-playwright-portfolio`.

## Résultat attendu

Chaque projet publié sur GitHub et destiné aux recruteurs a sa carte sur le portfolio.

## Résultat obtenu

Le portfolio renvoyait vers 4 dépôts sur 5 : le projet de tests, pourtant le plus parlant pour un poste en assurance qualité, n'y figurait pas. La section Compétences ne citait pas non plus Playwright.

## Comment il a été trouvé

En écrivant TC-API01, qui compare la liste des projets attendus aux liens présents sur la page : l'ensemble des liens ne contenait pas `qa-playwright-portfolio`.

## Correction

Ajout d'une carte « Tests automatisés de ce portfolio (QA) », grille des projets sur deux colonnes (4 cartes), Playwright et BDD ajoutés aux compétences.
