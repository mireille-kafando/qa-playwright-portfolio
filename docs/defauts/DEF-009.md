# DEF-009 : Un pourcentage de la démo des pièces passe sur deux lignes

| Champ | Valeur |
|---|---|
| Gravité | Cosmétique |
| Priorité | Basse |
| Statut | Corrigé avant la mise en ligne |
| Environnement | `/demo-pieces/`, Chromium 159, largeur 1 280 pixels |
| Test de non-régression | TC-C05 |

## Étapes pour reproduire

1. Ouvrir `/demo-pieces/` et envoyer une photo dont une classe dépasse 10 % (par exemple l'image synthétique des tests).

## Résultat attendu

Chaque pourcentage tient sur une ligne, aligné avec le nom de sa classe.

## Résultat obtenu

« 98,5 % » est coupé en deux lignes (« 98,5 » puis « % ») : la colonne de 52 pixels est trop étroite, et l'espace avant « % » autorise la coupure.

## Correction

Colonne élargie à 68 pixels et `white-space: nowrap` sur les pourcentages. Le test TC-C05 vérifie le format (« 98,5 % ») et que la hauteur de chaque pourcentage ne dépasse pas celle d'une ligne.
