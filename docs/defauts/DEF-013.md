# DEF-013 : Le nom accessible du bouton de langue ne contient pas son texte visible

| Champ | Valeur |
|---|---|
| Gravité | Mineure |
| Priorité | Moyenne |
| Statut | Corrigé (portfolio, commit `1cf0f2d`) |
| Environnement | Page d'accueil du portfolio, tous navigateurs |
| Règle | WCAG 2.2, critère 2.5.3 *Label in Name* (niveau A) |
| Test de non-régression | TC-A06, scénario BDD « Lire le portfolio dans ma langue » |

## Étapes pour reproduire

1. Ouvrir la page d'accueil.
2. Chercher le bouton par son rôle et son nom : `get_by_role("button", name="English")`.

## Résultat attendu

Le bouton est trouvé : son nom accessible contient le texte affiché, « English ». Une personne qui commande son ordinateur à la voix dit « cliquer sur English » et le bouton réagit.

## Résultat obtenu

Le bouton n'est pas trouvé : son attribut `aria-label` (« Changer de langue / switch language ») remplace le texte visible dans l'arbre d'accessibilité. Le test d'origine TC-P02 le contournait avec une expression régulière.

## Comment il a été trouvé

En écrivant le scénario BDD « Lire le portfolio dans ma langue » : l'étape « je choisis la langue « English » » cherchait le bouton par le texte qu'un utilisateur voit, et dépassait le délai.

## Correction

Suppression de l'`aria-label` : le nom du bouton est son texte (« English » ou « Français »). L'attribut `lang` du bouton indique la langue de ce texte, pour qu'un lecteur d'écran le prononce correctement. TC-P02 cherche désormais le bouton par son texte exact, et TC-A06 vérifie la règle sur les trois pages.
