# DEF-004 : Le résultat de la démo n'a pas d'alternative textuelle

| Champ | Valeur |
|---|---|
| Gravité | Mineure |
| Priorité | Moyenne |
| Statut | Corrigé (commit `34728d7` du portfolio) |
| Environnement | Chromium et Firefox ; audit automatisé de l'arbre d'accessibilité |
| Test de non-régression | TC-A05 |

## Étapes pour reproduire

1. Ouvrir `/demo-pietons/` et attendre l'analyse de l'image d'exemple.
2. Inspecter l'élément `canvas` qui affiche l'image annotée.

## Résultat attendu

Le résultat de l'analyse est accessible en texte, par exemple pour un lecteur d'écran.

## Résultat obtenu

Le `canvas` n'a ni rôle ni nom accessible : l'image annotée n'est perçue que visuellement.

## Correction

Donner au `canvas` le rôle `img` et une description mise à jour à chaque analyse (nombre de piétons et de cyclistes, modèle, seuil), répétée dans une zone `aria-live`.
