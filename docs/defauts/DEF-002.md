# DEF-002 : Étiquettes des boîtes coupées au bord de l'image ou superposées

| Champ | Valeur |
|---|---|
| Gravité | Mineure |
| Priorité | Basse |
| Statut | Corrigé (commits `23da9e2` et `e07e6f2` du portfolio) |
| Environnement | Chromium, largeur 1 200 pixels |
| Test de non-régression | Vérification visuelle (capture d'écran) |

## Étapes pour reproduire

1. Ouvrir `/demo-pietons/` avec l'image d'exemple.
2. Observer les étiquettes des boîtes situées au bord droit et des boîtes voisines.

## Résultat attendu

Chaque étiquette (classe et score) est lisible en entier.

## Résultat obtenu

L'étiquette de la boîte du bord droit est tronquée (« pedestrian 0 »). Avec le modèle v2, les étiquettes de deux piétons voisins se superposent.

## Correction

Borner l'étiquette à la largeur de l'image, puis décaler vers le bas une étiquette qui en chevauche une autre.
