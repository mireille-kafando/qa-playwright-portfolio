# DEF-011 : Le dépôt des tests n'a ni description ni sujets sur GitHub

| Champ | Valeur |
|---|---|
| Gravité | Mineure |
| Priorité | Moyenne |
| Statut | Ouvert : réglage à faire dans GitHub (case *About* du dépôt) |
| Environnement | API REST de GitHub, `GET /repos/mireille-kafando/qa-playwright-portfolio` |
| Test associé | TC-API04 (marqué « échec attendu » tant que le défaut est ouvert) |

## Étapes pour reproduire

1. Appeler `GET https://api.github.com/repos/mireille-kafando/qa-playwright-portfolio`.
2. Lire les champs `description` et `topics`.

## Résultat attendu

Comme les autres projets du portfolio : une description non vide, une licence et au moins 3 sujets. C'est ce qu'un recruteur voit en premier sur la page du dépôt et dans les résultats de recherche de GitHub.

## Résultat obtenu

`"description": null` et `"topics": []`. La licence (MIT) est présente.

## Correction prévue

Remplir la case *About* du dépôt : description, site web (le portfolio) et sujets (`playwright`, `pytest`, `qa`, `test-automation`, `e2e-testing`, `api-testing`, `bdd`, `github-actions`).

Le test TC-API04 est marqué `xfail` (échec attendu, non strict) pour ce dépôt : la CI reste verte tant que le défaut est ouvert, et le rapport affichera « XPASS » le jour où il sera corrigé. Il suffira alors de retirer la marque.
