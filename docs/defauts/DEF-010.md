# DEF-010 : La démo des pièces donne une probabilité élevée pour une image qui n'est pas une pièce

| Champ | Valeur |
|---|---|
| Gravité | Mineure |
| Priorité | Moyenne |
| Statut | Accepté comme limite connue ; avertissement ajouté sur la page |
| Environnement | `/demo-pieces/`, tous navigateurs |
| Test associé | TC-C02 (l'image synthétique des tests sert d'exemple) |

## Étapes pour reproduire

1. Ouvrir `/demo-pieces/`.
2. Envoyer `tests/donnees/piece_synthetique.png`, un disque gris dessiné avec un « 1 », qui n'est pas une vraie pièce.

## Résultat attendu

Le modèle signale qu'il n'est pas sûr, ou la page prévient que le résultat peut être faux.

## Résultat obtenu

Verdict « 2 roupies (98,5 %) ». Le modèle répartit toujours 100 % entre les 4 classes (couche softmax) et n'a pas de classe « autre ». Il associe probablement « disque gris sur fond uni » aux pièces de 2 roupies en acier, nombreuses à l'entraînement.

## Décision

Ce comportement vient du modèle, pas de la page. Le corriger demanderait une classe de rejet ou une détection des images hors distribution, ce qui dépasse le périmètre de la démo. La page indique désormais : « Le modèle choisit toujours l'une des 4 valeurs, même pour une image qui n'est pas une pièce : une probabilité élevée n'est pas une garantie. »
