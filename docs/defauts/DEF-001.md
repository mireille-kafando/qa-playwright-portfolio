# DEF-001 : La démo ne charge pas le moteur d'inférence (WebAssembly)

| Champ | Valeur |
|---|---|
| Gravité | Bloquante |
| Priorité | Haute |
| Statut | Corrigé avant la mise en ligne (commit `23da9e2` du portfolio) |
| Environnement | Chromium (Chrome headless), page servie par un serveur HTTP local, avant la première mise en ligne |
| Test de non-régression | TC-D01, TC-D08 |

## Étapes pour reproduire

1. Ouvrir `/demo-pietons/`.
2. Attendre le chargement du modèle.

## Résultat attendu

Le modèle se charge et l'image d'exemple est analysée.

## Résultat obtenu

Le message « Le modèle n'a pas pu être chargé » reste affiché. La console indique que le module `ort-wasm-simd-threaded.mjs` n'a pas pu être importé : le chemin relatif `ort/` passé à `ort.env.wasm.wasmPaths` n'est pas accepté par l'import dynamique, qui exige une adresse absolue.

## Correction

Construire l'adresse absolue avec `new URL('ort/', location.href).href`.
