# DEF-005 : Un fichier qui n'est pas une image est ignoré sans message

| Champ | Valeur |
|---|---|
| Gravité | Mineure |
| Priorité | Moyenne |
| Statut | Corrigé (commit `34728d7` du portfolio) |
| Environnement | Chromium et Firefox |
| Test de non-régression | TC-D05 |

## Étapes pour reproduire

1. Ouvrir `/demo-pietons/`.
2. Cliquer sur « Choisir une image » et choisir un fichier texte (le sélecteur le permet avec l'option « Tous les fichiers »), ou le glisser sur l'image.

## Résultat attendu

Un message indique que le fichier n'est pas une image.

## Résultat obtenu

Rien ne se passe : l'ancienne image reste affichée et aucun message n'apparaît.

## Correction

Afficher un message dans la zone d'état quand le type du fichier n'est pas `image/*`.
