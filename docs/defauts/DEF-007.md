# DEF-007 : La démo n'a pas d'image d'aperçu pour les partages

| Champ | Valeur |
|---|---|
| Gravité | Cosmétique |
| Priorité | Basse |
| Statut | Corrigé (commit `34728d7` du portfolio) |
| Environnement | Partage de l'adresse de la démo sur LinkedIn ou dans une messagerie |
| Test de non-régression | TC-P10 |

## Étapes pour reproduire

1. Inspecter l'en-tête de `/demo-pietons/`.

## Résultat attendu

Une balise `og:image` désigne une image d'aperçu valide, comme sur la page d'accueil.

## Résultat obtenu

Aucune balise `og:image` : le lien partagé s'affiche sans image.

## Correction

Ajouter une capture de la démo (`apercu.png`) et les balises `og:image` et `twitter:card`.
